# Saurabh Pagrut · Portfolio

Personal site for **[saurabhpagrut.in](https://saurabhpagrut.in)**. The design idea is "Saurabh, as an API": each section is an endpoint, and the hero shows the profile as the JSON response it resolves to.

Plain HTML, CSS and JavaScript with no framework and no dependencies, hosted on Netlify. A small Node script builds the page from one content file. Fonts and logos are served from the site itself, so the page makes no third-party requests.

```
src/
  content.js          everything the site says: profile, experience, skills, projects, education, contact
  page.js             the page's markup, built from content.js
  icons.js            line icons
  json-view.js        renders data as the highlighted JSON views
  util.js             date, duration and escaping helpers
build.js              writes public/index.html (node build.js --check tells you if it's out of date)
public/
  index.html          generated by build.js; don't edit it by hand
  assets/styles.css   design tokens and component styles (light + dark)
  assets/app.js       theme switch, background canvas, card hover, JSON toggles, skill filters, contact form
  assets/portrait-*   profile photo (480 and 960 px)
  assets/icons/       skill logos from Devicon (MIT), served locally
  assets/fonts/       Geist and Geist Mono variable fonts (OFL), served locally
  404.html            not-found page
  thanks/index.html   shown after sending a message with JavaScript turned off
  robots.txt, sitemap.xml
public/_redirects     www and *.netlify.app → saurabhpagrut.in
public/_headers       security and cache headers
netlify.toml          tells Netlify to run the build and publish public/
```

## Run it locally

Needs Node 18 or newer. There is nothing to install.

```bash
npm run build        # writes public/index.html from src/content.js
npx serve public     # or: python3 -m http.server -d public 3000
```

The contact form only sends on Netlify; locally the request has nowhere to go.

## Editing content

Edit `src/content.js`, run `npm run build`, and commit both `src/content.js` and the regenerated `public/index.html`. Netlify also runs the build on every deploy, so the live site always matches `content.js`.

The normal view and the **JSON** view of each section come from the same data, so you only change things once. Some examples:

- **Add a project:** add an entry to `projects.items` with `name`, `year`, `kind`, `tag`, `description`, `stack` and `links`. The Projects section and its nav link appear once it has at least one entry.
- **New role:** add it to the top of `experience.roles` and set the previous role's `end`. Durations and the "Current" badge are worked out from the dates.
- **New skill:** add it to a group in `skills`. Use `logo` for a file in `public/assets/icons/` or `glyph` for one of the icons in `src/icons.js`. Filter counts update by themselves.

Durations and the footer year are computed when the page is built, and `assets/app.js` keeps the ongoing durations current in the browser.

## Contact form

The form uses **Netlify Forms** (no server code and no secrets in the repo). Spam is filtered by Netlify plus a hidden honeypot field.

One-time setup in Netlify:
1. **Forms → Enable form detection**, then redeploy once.
2. **Site configuration → Notifications → Emails and webhooks → Form submission notifications → Add notification → Email notification**, once for `getsaurabhpagrut@gmail.com` and once for `hello@saurabhpagrut.in`, form `contact`.
